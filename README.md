# 충전이 필요해!

배터리가 다 떨어져 가는 카페 청소 로봇이, 충전 독의 플러그를 뽑고 콘센트를 독차지한 손님을 한 명씩 떠나보내는 짧은 퍼즐 게임이다.
플레이어는 카페 바닥을 한 칸씩 자유롭게 움직이며 의자나 진동벨 같은 물건을 밀고, 콘센트를 차지한 손님(콘센트 빌런)이 스스로 플러그를 뽑고 떠나게 만든다. 되돌리기와 처음부터는 언제든 할 수 있고, 실패해도 벌칙이 없다.

시리어스 게임 강의의 수업 중 체험 활동으로 만들었다. 수업에서 "누군가 또는 무언가의 권리가 침해당하는 상황"을 써내고 그것으로 간단한 게임을 만드는 활동이었다.

## 해 보기

https://soomin007.github.io/outlet-villains/

키보드는 방향키(또는 WASD)로 걷고, Z로 되돌리고, R로 처음부터 다시 한다. 휴대폰은 화면 아래 방향 버튼을 쓴다.
위쪽 ◐ 버튼은 그림체(흑백과 컬러 카툰)를 바꾸고, ♪ 버튼은 소리를 켜고 끈다.

## 만든 방식

빌드 도구 없이 HTML, CSS, JavaScript만으로 만들었다. 게임 규칙과 판은 Claude Code가, 그림은 Codex가 이미지 생성으로 만들었다.
음악은 Suno로 만들었고, 무료 플랜으로 만든 곡이라 비상업적 용도로만 쓴다. 그림체를 맞출 때 참고한 다른 게임의 이미지는 저작권 때문에 이 저장소에 넣지 않았다.

이 게임은 `soomin007/magic-straw` 저장소에서 여러 번 방향을 바꾼 끝에 나왔다(마법 빨대 카페 퍼즐, 물의 정령, 물리 퍼즐 시제품).
그 시도들과 경위는 그 저장소에 남아 있다.
