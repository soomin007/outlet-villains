# 오디오

이 폴더의 음악은 사용자가 Suno(무료 플랜)로 만든 것이다(2026-10-29). Suno 무료 플랜으로 만든 곡은 비상업적 용도로만 쓸 수 있으므로,
이 게임처럼 수업 시연에만 쓰고 판매하거나 광고에 쓰지 않는다. 만들 때 쓴 프롬프트는 `docs/concept.md`의 "Suno 프롬프트" 절에 있다.

| 파일 | 쓰임 |
|---|---|
| `bgm-cafe.mp3` | 퍼즐 중에 반복하는 배경 음악. 앞뒤의 짧은 무음은 게임 코드가 잘라 내고 끊김 없이 반복한다 |
| `jingle-clear.mp3` | 판을 깼을 때 한 번 나오는 짧은 음악 |

`jingle-clear.mp3`는 2026-10-29부터 쓰지 않는다. 노래 한 곡에서 잘라 쓰는 클리어 음악이 짧은 퍼즐 판과 맞지 않아서, 게임이 배경 음악과 같은 조(D단조의 나란한조 F장조)로
1.8초짜리 화음을 직접 합성한다(index.html의 `Sound.chime`).

## 효과음 (`assets/sfx/`)

사용자가 ElevenLabs로 만든 효과음이다(2026-10-29). 파일마다 크기가 크게 달라서(가장 큰 0.1초 구간 기준 -44dB에서 -16dB까지),
게임이 파일마다 다른 크기를 곱해 -20dB에 맞춘다. 곱하는 값과 잰 값은 index.html의 `SFX` 표에 있다. 파일을 바꾸면 다시 재서 그 표를 고친다.

| 파일 | 쓰임 |
|---|---|
| `chair.mp3` | 물건을 밀 때. 의자는 그대로, 쓰레기통과 진동벨은 더 높고 작게 튼다 |
| `bump.mp3` | 막혀서 못 갈 때 |
| `shutter.mp3` | 화각에 들어가 들킬 뻔할 때, 쓰레기통이 방송에 잡힐 때 |
| `buzzer.mp3` | 진동벨이 빌런 귀 옆에서 울릴 때 |
| `plug.mp3` | 빌런이 떠나고 내 충전기가 꽂힐 때 |
